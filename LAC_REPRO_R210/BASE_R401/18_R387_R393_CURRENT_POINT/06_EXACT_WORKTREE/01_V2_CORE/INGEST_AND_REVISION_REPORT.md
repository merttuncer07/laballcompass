## Chronological method evolution recovered

1. **Novelty/core-collision phase:** candidates were demoted when they matched mature theory or an
   existing core. This protected ontology cleanliness but suppressed useful applied products.
2. **Value-first correction:** novelty was removed from the priority objective. All 211 candidates were
   rescored for economic/social impact, breadth, deployability, performance, evidence and robustness.
3. **r49 expansion:** the branch reached 91 executable top-level classes and retained corrected/failed
   benchmark history.
4. **Later product-validation conversation:** focused unit tests were separated from real-world
   validation; held-out transfer, hidden ground truth, strong baselines, analogue-versus-domain-native
   data and PP1–PP3 proof levels became explicit.
5. **Current project correction:** negative real-world evidence must locate a working boundary and guide
   routing/redesign. It must not be used as a global product-killing device.

## Problems in the old “core” count

- A top-level class was counted as a core even when it was an internal helper. `TruncatedPoolRankV0` is
  the clearest example.
- “distinct core,” “distinct product,” “executable class” and “new scientific idea” were sometimes
  treated as the same thing.
- Nine rows were globally labeled `CLOSED_FAIL_STRONG_BASELINE`, although the stored evidence only
  establishes a comparator loss in the tested shell.
- Some useful components were treated as ontology inflation rather than retained capabilities.
- Promotion gates could dominate the observed effect. RX-149 gains 8.70% with a 99.89% win rate but was
  called non-surviving because a chosen standalone threshold was 12%.
- The latest timestamp could contain less comparator information than an earlier valid replication.
  RX-138's 12:10 r02 run contains a simple-repair comparator; the later 12:18 replication omits it.
- The r50 rescue contains results but not executable source for its five candidates. Those records cannot
  honestly be called imported executable cores yet.
