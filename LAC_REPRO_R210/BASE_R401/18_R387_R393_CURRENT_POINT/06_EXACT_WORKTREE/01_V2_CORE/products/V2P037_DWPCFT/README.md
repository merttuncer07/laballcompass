# V2P037 DWPCFT — Decision-Weighted PCFT Calibration Allocator

PCFT can identify a merge-tolerance boundary while still spending calibration samples uniformly across harmless and consequential parts of that boundary. DWPCFT allocates a finite calibration budget by downstream consequence and inverse distance to the closure/fidelity boundary, using the diminishing marginal reduction of an explicit inverse-square-root uncertainty proxy.

The current uncertainty law is a declared synthetic shell; real calibration-error scaling must be replaced by domain-native evidence before deployment.
