# V2P029 SUSCA — Support-Adjusted Shared Capacity Allocator

BOSA-style effective support is not treated as a report attached after allocation. It changes the value ordering that enters a shared-capacity polymatroid allocation and can hard-exclude survivor cohorts below a declared support floor. The composition therefore prevents a nominally valuable but selection-fragile item from consuming capacity shared with better-supported items.

The mechanism-removing comparator gives every item support 1.0. Evidence is deterministic mechanism-level only; support fractions and pool capacities remain declared inputs.
