# V2P006 IDASRO

Identification-Driven Admissible-Shift Robust Optimizer.

Primitive: scalar identification uncertainty -> certified affine sensitivity into a downstream quadratic decision mean -> one-dimensional admissible shift set -> exact directional robust action.

The sensitivity map is an explicit external contract. Without a certified map and provenance, the adapter emits the P025 identification envelope but refuses to manufacture a robust vector decision.
