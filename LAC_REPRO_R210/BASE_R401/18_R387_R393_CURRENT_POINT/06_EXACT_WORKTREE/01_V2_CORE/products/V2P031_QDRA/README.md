# V2P031 QDRA — Quasineutral Decision-Relevant Resolution Allocator

QAIG's validity-boundary idea is lifted from a single acquire/skip decision into a shared resolution budget. ACRA receives consequence weights discounted by the probability that measurement uncertainty can actually change the declared validity decision. A far-from-boundary region therefore cannot monopolize fine resolution merely because its raw consequence number is large.

The current benchmark uses a Gaussian boundary-mass approximation and synthetic regions; it is not a physical calibration claim.
