# P044 MFTS v0.1 — Manufacturing-Feasibility Tipping Surface

## Composition
FCMS → TDSX. FCMS certifies rank-one-compatible laminate construction; TDSX finds where fabrication assumptions make that same mathematical laminate unmanufacturable.

## Benchmark result
The target gradient is synthesized exactly by a depth-1 50/50 laminate. At baseline thickness **1.0** and minimum feature **0.4**, the smallest layer is **0.5** and fabrication margin is **+0.1**. The declared sensitivity surface contains a nearest flip where the target remains mathematically exact but the minimum feature exceeds the available layer scale.

## Claim boundary
Mathematical compatibility and fabrication feasibility are separate certificates.
