# R211 — Volterra active-probe transfer test

R205 Proposition 4 identifies a symmetric rank-r quadratic Volterra kernel from
exact bilinear oracles. This round tests the noisy transfer claim left open
there: reset-and-replay responses with i.i.d. noise, rank selected from data
(not truth), rank 0 included, and abstention on a dedicated calibration draw.

## What is implemented

- `probe_transfer.py`
  - Quadratic oracle with offset, linear, and quadratic terms; every query
    returns `n` iid replications (never collapsed).
  - Factor-only learner: `FactorModel` carries offset, linear vector,
    orthonormal basis, and small core. No `m x m` dense kernel is formed.
  - Rank selection scores all candidates (0..3) on one shared validation
    draw; the true rank never enters selection.
  - Abstention uses its own calibration draw, disjoint from train/heldout.
  - Oracle sample accounting is verified: reported totals equal actual raw
    response draws made through the meter (regression-tested).
  - Hand-computed noiseless check: `y = 1 + [2,-1,0.5].z + 3 z1^2` is
    recovered end-to-end with zero error.
- `test_probe_transfer.py` — 6 unittest cases (replication integrity, hand
  example, factor-only model, sample accounting).
- `R211_RESULT.json` — generated by `python probe_transfer.py`, seeded.

## Verified results (seeds 0-2, m=12, sigma 0.05, equal raw training samples)

- Hand verification absolute error: 0.0.
- Equal-budget comparison per control (mean heldout RMSE, 3 seeds):

| Control | Active factor learner | Dense quadratic ridge | Linear ridge |
|---|---|---|---|
| low_rank (rank-2 truth) | 0.0266 | **0.0095** | 1.4915 |
| linear_only | 0.0269 | 0.0095 | **0.0087** |
| full_rank | 5.1527 (abstains) | **0.0094** | 5.0479 |
| quartic (non-quadratic) | 0.9946 (abstains) | 1.1025 | 2.4505 |

- **Key reversal:** under equal training-sample budgets the dense quadratic
  ridge baseline beats the active probing learner even on its home field
  (low-rank truth). The earlier "active wins" claim came from unequal budgets
  (~25x more oracle draws for the active learner) and is withdrawn.
- The learner's stored parameters are far fewer (67 vs 91 at m=12), and on
  full-rank truth the abstention diagnostic fires correctly (3/3) while the
  dense baseline cannot abstain.
- Rank selection remains noisy under equal budgets: picks are spread over
  2-3 even when the true rank is 2.
- The quartic control shows the probing machinery degrades gracefully but
  does not identify a non-quadratic response.

## Crossover: where the factor learner starts to win (measured, seeds 0-4)

At m=12 dense ridge wins (0.020 vs 0.055 RMSE). At m=100, rank-2 truth,
equal raw training samples, the ordering reverses decisively:

| m | active wins | active RMSE | dense RMSE | factor params | dense params |
|---|---|---|---|---|---|
| 12 | 0/5 | 0.055 | 0.020 | 41 | 91 |
| 25 | 0/5 | 0.069 | 0.025 | 76 | 351 |
| 50 | 0/5 | 0.131 | 0.072 | 151 | 1326 |
| 100 | **5/5** | **0.138** | 7.225 | 301 | 5151 |

This is the parameter-count gap predicted by the algebra (O(mr) vs O(m^2))
showing up empirically: dense ridge needs ~N >> p samples; once p ~ 5151
outgrows the equalized budget, the factor learner's O(mr) structure wins.
The reversal is a measured regime shift, not a theorem; probe amplitudes
and query locations are still not equalized.

## Higher-order engine (orders 3 and 4, added after the crossover)

`probe_multilinear` generalizes the 4-point bilinear polarization to order-d:
`T(v_1..v_d) = (1/(2^d d!)) sum over sign vectors of ±T evaluated at
Σ s_i v_i` — 2^d reset-and-replay queries per multilinear form evaluation,
exact in noiseless arithmetic. `recover_multilinear` then (a) builds the
column-space image with `mr` trilinear-style probes against random side
vectors, (b) orthonormalizes to an m×r basis, (c) measures the r^d core
directly. No dense m^d tensor is ever formed; storage is mr + r^d.

Verified noiseless (27-cell grid, orders 2-4, m up to 40, ranks to 5):
- worst relative core error 1.24e-15 (machine precision).
- Verified noisy (sigma 0.01/0.05, n=4096 replications per query): worst
  relative core error 3.9e-4, scaling as expected with sigma/sqrt(n).

Query counts per kernel: image phase m*r*(2^d) response draws, core phase
r^d*(2^d). Compare passive dense regression needing m^d features.

## CP factor extraction (order 3): the r^d core cost is now optional

`extract_cp_factors` recovers the actual rank-1 components — factor
directions AND absolute weights — via generalized eigendecomposition of two
random slices: `S_t = G^T diag(w_a (f_a.w_t)) G`, whose eigenvalues are the
exact weight ratios and whose eigenvectors are exactly the columns of G^{-1}
for ANY invertible G (no orthogonality needed — verified at 1e-14 spread).
Absolute weights come from a rank-r least squares on the r^3 core
(`core=...` argument); without it, weights are returned up to per-factor
scale. Joint (w, f) sign flips are canonicalized by construction.

Stress grid (20 cells: ranks 2-6 x m in {8,20,40,60} x 5 seeds,
NONORTHOGONAL factors, worst Gram off-diagonal ~0.45):
- kernel reconstruction from recovered CP: worst relative error 5.7e-12.
- Full ambient tensor never formed anywhere in the extraction path.

Cross-domain control: on a generic full-rank symmetric tensor forced into
rank-3 CP, the engine does NOT silently succeed — kernel error >1.0 and
held-out probe residual 0.93. Regression-tested.

What remains open: exact Kruskal-style identifiability bounds under noise,
and order-4+ factor extraction (the 2-direction eig trick is order-3).

## Honest limitations

- Equal raw sample counts do NOT equalize probe amplitudes, computation, or
  query locations (wall 4).
- The synthetic quadratic oracle is NOT evidence that real agent memory is
  quadratic or low-rank (wall 5 is the actual test).
- The linear_only control shows the factor learner paying probe overhead to
  recover what the linear baseline gets for free; low-rank identification is
  only worth its cost when the quadratic term actually matters.
- The crossover table is consistent with the O(mr) vs O(m^2) parameter gap
  but confounded by regularization behavior of ridge at large p; a clean
  asymptotic claim needs the sample-complexity analysis (part of wall 4).
- The r^d core measurement is exact but its size still grows exponentially
  in the order d; the engine removes the m^d ambient tensor, not the r^d
  core cost. For order 3 the core is only needed for absolute weights
  (wall 6 removes even that); order-4+ factor extraction is wall 1.
- CP identifiability under noise is empirically graceful but unproved
  (wall 2); degenerate weight ratios are handled by neither theory nor
  retry logic yet (wall 3).
- The sequential-control gap is wall 5; the removed toy control was
  unfalsifiable and a real online-probing task is its replacement.
- No lint/typecheck commands exist in this repo; verification is unittest +
  py_compile.

## Open walls (each is a named target, not a disclaimer)

1. **Order-4+ factor extraction.** The 2-direction generalized-eig trick
   works at order 3 because slices collapse to G^T D G. At order 4 the
   analogue is fourth-order simultaneous diagonalization (whitening +
   JDTM/joint-diag); nobody in the active-probing lane has done it. First
   concrete step: extract the order-4 whitener from r^2 random slices, then
   jointly diagonalize r^2 of them.
2. **Noisy identifiability theorem.** Empirical degradation is
   sigma/sqrt(n)-graceful, but there is no proved error bound for CP
   extraction under probe noise. The robust-Kruskal machinery (Bhaskara et
   al. 2013) is the known tool that has never been combined with active
   probing. Concrete step: perturbation analysis of S1^{-1}S2 eigenvectors
   under entrywise noise -> explicit (sigma, n, gap) -> error bound.
3. **Degenerate weight ratios.** Colliding eigenvalues (w_a (f_a.w2) /
   w_a (f_a.w1) equal for two components) are a real failure mode with no
   retry/resolution logic yet. Concrete step: detect near-collisions from
   the eigengap, re-draw w1/w2 (each retry costs only 2 slices), and prove
   a genericity bound on how many redraws suffice.
4. **Equal-amplitude equal-budget comparison.** Raw sample counts were
   equalized, not probe amplitudes or query locations. Concrete step: an
   amplitude-constrained oracle model where every query has bounded norm,
   making the comparison budget-fair by construction.
5. **Sequential/agent transfer.** All experiments use reset-and-replay
   batch access. A sequential task where probes must be chosen online, with
   no reset, is the actual agent-memory claim. Concrete step: an episodic
   task where the learner chooses which history to probe next (active
   experiment design), measured against passive trajectory baselines.
6. **Core-free absolute weights at order 3.** Directions and relative
   weights need no core; absolute weights currently use the r^3 core.
   Concrete step: recover ||P f_a|| from the image-phase second moments
   (r extra probes per factor), removing the core entirely.

Each wall has a first concrete step and a falsifiable target; none is
hand-waved away.
