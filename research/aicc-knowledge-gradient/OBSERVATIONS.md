# AICC: observed computation and published implementation

The lab's original AICC used 31-node Gauss–Hermite quadrature to integrate the maximum of affine action utilities. This maximum has kinks at decision boundaries. For `max(0,Z)` under a standard normal, the old calculation returns 0.3883595356446188 while the closed form is 0.3989422804014327. At cost 0.393, the old code rejects a measurement with positive expected net value. This is an engineering counterexample, not observed field loss.

Actual upstream code read: Frazier, Powell & Dayanik's [archived implementation](https://github.com/INFORMSJoC/1080.0314), specifically [LogEmaxAffine.m](https://github.com/INFORMSJoC/1080.0314/blob/main/ckg/LogEmaxAffine.m), [AffineBreakpoints.m](https://github.com/INFORMSJoC/1080.0314/blob/main/ckg/AffineBreakpoints.m), and its preprocessing function. It removes duplicate slopes/dominated lines, constructs the upper envelope and sums normal expected-improvement terms. The implementation computes the logarithm of the value for extreme tails. Source bytes, hashes and MIT license are preserved here. These research files are not imported by the lab.

The repaired AICC uses the same established mathematical identity in a new Python implementation. It sums nonnegative normal-loss contributions over envelope breakpoints; no quadrature grid is required. Tail terms use an asymptotic series past 10 standard deviations. Unlike the upstream log-value implementation, this API returns ordinary floating-point utility; values below representable range may underflow to zero. No novelty or improved performance over the published algorithm is claimed. Tests use a two-action closed form and independent numerical integration over all pair crossings, including dominated lines. MATLAB itself was not executed.

The prior update routine correctly models **fresh independent noise at every call**. That interpretation is wrong when used to replay the same observation, but repeated equal values do not by themselves establish replay. An opt-in finite observation model now accepts a named channel-error covariance `R`, with `y=H x+epsilon` and initially independent state/error. It conditions an augmented Gaussian `[x,y]` by projecting a square-root factor, keeping singular shared-error structure instead of adding independent jitter. Remaining measurement means, state cross-covariances and variances are conditioned together. This is standard Gaussian conditioning, not a learned dependence detector.

We also read upstream `belief/BayesUpdateNaive.m`, whose own warning recommends its block update because covariance subtraction can lose precision. The lab's finite model uses a factor projection instead of that naive covariance subtraction. We did not copy its post-hoc diagonal-jitter repair. The lab's default fresh-measurement Joseph update remains intact.

Effects to preserve: finite replay is idempotent; declared perfect copies have zero remaining value after observing one; independent equal-valued channels still reduce uncertainty; partial positive or negative error correlations match direct batch conditioning; contradictory deterministic observations are rejected. Costs and utility slopes remain supplied model assumptions. This is one-step expected value, not a globally optimal acquisition policy or an audit recommendation.

Paper: Frazier, Powell & Dayanik (2009), [The Knowledge-Gradient Policy for Correlated Normal Beliefs](https://doi.org/10.1287/ijoc.1080.0314); software DOI [10.1287/ijoc.1080.0314.cd](https://doi.org/10.1287/ijoc.1080.0314.cd).
