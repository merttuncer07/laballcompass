# R400 JARB controlled experiment

JARB tests a higher-order interaction between V2P057-style observability selection and V2P054-style consequence-adaptive representation. Both stages draw from one caller-declared total budget. The candidate recognizes that fine representation has no value for an entirely unobserved state; the removal control deletes only this acquisition/representation interaction while preserving weights, sensor geometry, feasible decisions, costs, total budget, and deterministic tie-breaking.

The synthetic discriminating shell is deliberately narrow. Correct declared consequence changes the joint decision and lowers declared joint loss. A miscalibrated consequence vector can reverse the result. Minimum and maximum budgets collapse exactly to the removal control.

Status: experiment only, not V2P059 and not part of R399 authority. Evidence is deterministic mechanics, not empirical validation or novel theory.
