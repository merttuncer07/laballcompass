# BPISD v0.1 — Binary Persuasion Information-Structure Designer

BPISD computes receiver actions across posterior beliefs, concavifies sender value with a Bayes-mean
constraint, and returns implementable signal likelihoods conditional on each binary state. It compares
the optimized channel with no information and full revelation and verifies Bayes plausibility.

BPISD is a standalone disclosure, recommendation, warning, and strategic communication design product.
Current-product integration is not required.

Run `python -m unittest -v test_bpisd.py` and `python demo_persuasion.py`.
