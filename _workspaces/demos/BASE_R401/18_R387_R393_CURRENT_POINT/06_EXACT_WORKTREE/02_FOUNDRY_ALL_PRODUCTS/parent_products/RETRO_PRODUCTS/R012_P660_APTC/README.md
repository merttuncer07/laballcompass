# APTC v0.1 — Ambipolar Packet Transport Calculator

APTC reconstructs ambipolar diffusion from measured electron and hole density profiles. It computes
the electric field generated by attempted differential diffusion, the resulting electron/hole
fluxes, the neutral-limit ambipolar diffusion coefficient, charge-imbalance diagnostics, and future
packet spreading.

The calculator explicitly compares uncoupled flux separation with the field-coupled residual. It
only labels the packet model valid when fluxes match and the supplied profiles remain nearly neutral.
This is directly usable for semiconductor, plasma, electrolyte, and charged-carrier transport work.

Run `python -m unittest -v test_aptc.py` and `python demo_ambipolar.py`.
