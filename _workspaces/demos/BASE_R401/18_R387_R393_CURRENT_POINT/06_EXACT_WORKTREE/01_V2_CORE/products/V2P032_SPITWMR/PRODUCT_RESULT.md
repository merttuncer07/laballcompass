# V2P032 SPITWMR — Search-Policy Information Targeted Model Reduction

SPIA says which latent directions can change the search policy. SPITWMR converts that policy sensitivity into TWMR's protected output, then removes state dimensions while minimizing error in the policy-relevant impulse response. This can retain a low-energy but decision-critical state that ordinary state-energy reduction deletes.

This is a linear-system mechanism benchmark, not a claim that the supplied policy sensitivity is calibrated in a real search domain.
