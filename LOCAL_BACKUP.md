# Yerel çalışma kopyası ve GitHub yedeği

Güncel yerel klasör: `/Users/mertalituncer/Developer/lab`.
Özel GitHub deposu: https://github.com/merttuncer07/laballcompass

Bu klasör, Documents/iCloud altındaki çalışma kopyasından kurtarıldı. Kaynak dosyalar silinmedi. Eksik dosyalar ya özgün iCloud içeriği indirilerek ya da ilgili paket manifestindeki SHA-256 özeti ve boyutuyla birebir eşleşen yerel kopyadan tamamlandı. Sonuç sayıları LOCAL_BACKUP_STATUS.json içindedir. Eski bozuk Python ortamı ve kurtarma kayıtları `.local-recovery/` altında yerelde korunur; GitHub'a yeniden kurulabilen ortamlar ve önbellekler yüklenmez.

Bundan sonraki çalışma ve dosya yüklemeleri için bu **Developer/lab** klasörünü kullan. Önceki Codex sohbeti Documents altındaki eski konuma bağlıdır; o sohbette yapılan sonraki değişiklikler bu yedeğe kendiliğinden taşınmaz. GitHub da yalnız commit ve push yapılan değişiklikleri saklar. GitHub Desktop'ta bu yerel klasörü mevcut depo olarak ekleyip değişiklikleri Commit ve Push ile yedekleyebilirsin.

Bu işlem Mac'in genel iCloud kota sorununu değiştirmez; proje için iCloud dışında yerel çalışma ve GitHub üzerinde ikinci kopya sağlar. Python bağımlılıkları requirements.lock ile yeniden kuruldu. Dosya kurtarma, labın bütün algoritmalarının veya bilimsel iddialarının doğrulaması değildir.
