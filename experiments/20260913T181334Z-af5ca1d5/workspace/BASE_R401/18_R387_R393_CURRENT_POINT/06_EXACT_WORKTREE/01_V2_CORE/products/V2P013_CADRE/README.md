# V2P013 CADRE — Compression-Aware Decision-Relevant Explorer

P091 decision-compression tipping supplies a decision-error budget to DRE. A compressed DRE choice is accepted only when its top-two score margin exceeds the declared compression bound; otherwise the product routes to full-resolution DRE or abstains.

This prevents state-budget compression from silently changing the exploration decision. Evidence is deterministic mechanism-level only.
