# V2P030 PCFDLW — Predictive-Closure-Fidelity Decision-Loss Workbench

DLEW can correctly optimize downstream action regret and still choose a recursively invalid compressed representation. PCFDLW therefore requires P141-style closure and predictive-fidelity certification before a candidate is allowed into the decision-loss comparison. If no candidate survives, it abstains rather than laundering an invalid state representation through a good current-period decision score.

Evidence is synthetic mechanism-level only. The closure and fidelity metrics must be obtained independently from the represented process.
