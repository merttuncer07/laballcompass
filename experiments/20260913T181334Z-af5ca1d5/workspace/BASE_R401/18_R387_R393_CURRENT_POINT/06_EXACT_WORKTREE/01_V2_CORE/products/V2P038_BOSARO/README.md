# V2P038 BOSARO — Burnout-Support Admissible-Shift Robust Optimizer

A declared shift radius is too optimistic when the cohort supporting the estimate has eroded. BOSARO converts BOSA effective support into the radius of K068's admissible directional uncertainty set: radius grows as inverse square root of effective support. The robust optimizer then reduces exposure to the fragile shift direction rather than merely reporting that support is weak.

The support-to-radius law and two-action grid optimizer are explicit development assumptions, not a calibrated finance or control model.
