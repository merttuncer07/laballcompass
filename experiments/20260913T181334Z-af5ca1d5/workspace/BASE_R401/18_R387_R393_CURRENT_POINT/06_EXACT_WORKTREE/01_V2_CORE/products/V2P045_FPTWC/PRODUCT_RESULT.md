# V2P045 FPTWC — Failure-Path Tipping Testing-Wealth Controller

FPTE supplies how close the current architecture is to a failure-retention tipping point. That state changes the temporal profile of a fixed sequential-testing budget: near a tipping point the same wealth is front-loaded to tests that can resolve the impending failure path. The removal comparator preserves the p-values, alpha and TestingWealthController but removes FPTE coupling.
