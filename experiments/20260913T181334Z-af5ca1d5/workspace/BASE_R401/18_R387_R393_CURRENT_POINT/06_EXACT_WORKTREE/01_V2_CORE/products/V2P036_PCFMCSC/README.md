# V2P036 PCFMCSC — Predictive Closure-Fidelity Comparative-Statics Certificate

PCFT maps where predictive-state merging fails, but a single nearest tipping point can hide recovery or reversal farther along the tolerance path. PCFMCSC treats the PCFT joint margin as an ordered payoff table and checks the structural direction explicitly. It returns the first monotonicity violation and all safe tolerance intervals rather than assuming one threshold separates good from bad compression.

This is a finite-grid structural certificate, not an extrapolation outside the evaluated tolerance grid.
