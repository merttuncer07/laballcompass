# TFLD v0.1 — Time-Frequency Localization Designer

TFLD measures real time and frequency energy spreads for candidate analysis windows and selects one
meeting declared joint limits. It reports uncertainty product, duration, FFT bin spacing, equivalent
noise bandwidth, requirement ratios, and the closest quantified compromise when no candidate is
feasible. TFLD is a standalone sensing and signal-analysis design product; integration is unnecessary.

Run `python -m unittest -v test_tfld.py` and `python demo_localization.py`.
