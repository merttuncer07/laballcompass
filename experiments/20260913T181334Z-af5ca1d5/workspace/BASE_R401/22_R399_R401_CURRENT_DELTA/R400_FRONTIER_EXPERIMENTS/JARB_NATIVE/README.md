# R400 JARB-Native experiment

This is the stricter successor to the rejected first JARB prototype. It does not replace either parent optimizer. For each feasible total-budget split it calls the exact R399 V2P057 REOC sensor selector and exact R399 V2P054 CADSBC representation allocator, then tests whether acquisition/representation complementarity should choose a different split from an additive removal control.

The candidate remains an experiment, not V2P059. Promotion requires a sensitivity sweep and explicit family-quality adjudication.
