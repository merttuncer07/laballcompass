# LabAllCompass — start here

The laboratory now has one coherent active core. Historical archives remain on
disk, but daily operation begins here rather than by searching old ZIPs or
reconstructing a prior chat.

## The only normal entrypoint

From this folder run `./lab.ps1 durum`, or simply state the outcome you want in
Codex. The root command refreshes Mission Control and shows what is running,
what is next, retained failures, recent evidence/products, and one safe next
action. The generated dashboard is disposable; it never replaces an authority
database.

## If Codex is available

Open this local project and state the outcome you want. `AGENTS.md` and the Lab
skill route the request through typed runtime state. Codex uses Git diffs and,
after the baseline commit, worktrees for isolated implementation work.

## If Codex compute is unavailable

Use ordinary chats in one ChatGPT Project. Upload
`CHATGPT_SUPPLEMENT_MESH/exports/LABALLCOMPASS_CHATGPT_PROJECT_COMPANION_R2_2026-08-28.zip`
once and put its `PROJECT_INSTRUCTIONS.md` in Project instructions. Then state a
useful outcome naturally. At a meaningful `LABSUP_` milestone, use **Save to
project** once. Successor chats read the saved Project source; you do not carry
work orders or reports between them.

When Codex returns, open one collector chat in that Project and say
`CODEX PAKETİ HAZIRLA`. Download its one return artifact and attach it here.
ChatGPT Work remains an optional local-execution interface, but it shares the
Codex/Work compute boundary and is not the continuity mechanism.

Advanced queues, internal lanes, worktrees, and review gates stay hidden until the work
has real dependencies or integration risk. Small direct tasks remain direct.

## Where truth lives

- `LABALLCOMPASS_RUNTIME`: typed job and transition state.
- `LABALLCOMPASS_COHERENCE_OS`: scientific catalog and provenance.
- `TURING_ALLCOMPASS_MACHINE`: explicit scientific rounds only.
- `LABALLCOMPASS_CONTROL_PLANE`: bounded supplementary work while Codex is away.
- Git: reviewable code/snapshot history, not scientific truth.

Do not import chat prose directly as canonical state. Do not restart the Lab
because a conversation ended. Continue from the relevant runtime.
